    • Read from the operator's own page.

      Every date and price on getPackd comes from the operator's website. This page uses the snapshot taken on 4 November 2026.

    • The only thing ever added is GST.

      If an operator says GST is extra, we add 5% so prices compare fairly. 116 trips in this snapshot say it is. Nothing else is added.

    • You book with the operator.

      No payment happens on getPackd. You enquire, then pay the operator directly, on their terms.
